## ADDED Requirements

### Requirement: 删除文件移至回收站
执行删除文件/文件夹操作时，系统 SHALL 使用 `trash` 将目标移至系统回收站（而非永久删除），并在操作回滚日志中记录一条条目（类型：delete，路径，时间戳）。

#### Scenario: 删除文件进入回收站
- **WHEN** 用户确认删除文件 `src/index.ts`
- **THEN** 该文件进入系统回收站，文件树节点消失，操作日志新增一条 delete 记录

#### Scenario: 删除目录进入回收站
- **WHEN** 用户确认删除非空目录
- **THEN** 整个目录递归进入系统回收站，文件树对应节点树消失

### Requirement: 操作回滚日志
系统 SHALL 维护一个操作回滚日志（内存 + 持久化至 `~/.agent-engine/undo-log.json`），记录最近 50 次删除与重命名操作；用户可通过 Ctrl+Z（在文件树聚焦时）撤销最近一次删除（从回收站还原）或重命名（执行反向重命名）。

#### Scenario: 撤销删除
- **WHEN** 用户删除文件后在文件树聚焦状态下按 Ctrl+Z
- **THEN** 系统从回收站还原该文件至原路径，文件树刷新，操作日志移除该条记录

#### Scenario: 撤销重命名
- **WHEN** 用户将 `a.ts` 重命名为 `b.ts` 后按 Ctrl+Z
- **THEN** 系统将 `b.ts` 重命名回 `a.ts`，文件树刷新

#### Scenario: 超出 50 条日志
- **WHEN** 操作日志已有 50 条时再执行一次删除
- **THEN** 最旧一条日志条目被丢弃，新条目追加在末尾
