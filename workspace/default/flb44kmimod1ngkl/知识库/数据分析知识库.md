# 📊 数据分析知识库

## 一、数据分析基础概念

### 1.1 数据类型
- **数值型数据**：连续型（身高、体重）、离散型（人数、次数）
- **分类数据**：名义型（性别、颜色）、有序型（等级、评分）
- **时间序列数据**：按时间顺序排列的数据点

### 1.2 描述性统计
| 指标 | 说明 | 适用场景 |
|------|------|---------|
| 均值 (Mean) | 算术平均数 | 数据分布对称时 |
| 中位数 (Median) | 中间值 | 数据有异常值时 |
| 众数 (Mode) | 出现最多的值 | 分类数据 |
| 标准差 (Std) | 数据离散程度 | 衡量波动性 |
| 四分位数 (Quartile) | 数据分布位置 | 箱线图分析 |

### 1.3 常用分析方法
- **相关性分析**：Pearson / Spearman 相关系数
- **回归分析**：线性回归、逻辑回归
- **聚类分析**：K-Means、层次聚类
- **分类算法**：决策树、随机森林、SVM
- **时间序列**：ARIMA、指数平滑

## 二、数据清洗原则

1. **缺失值处理**：删除、均值填充、中位数填充、插值法
2. **异常值检测**：3σ原则、IQR方法、Z-Score
3. **数据标准化**：Min-Max归一化、Z-Score标准化
4. **重复数据处理**：去重、合并

## 三、数据可视化

### 常用图表类型
- 📊 **柱状图**：比较不同类别
- 📈 **折线图**：展示趋势变化
- 🥧 **饼图**：展示占比

- 🔥 **热力图**：展示相关性矩阵
- 🌊 **散点图**：展示两个变量关系

## 四、SQL常用查询

```sql
-- 聚合查询
SELECT 部门, AVG(薪资) as 平均薪资, COUNT(*) as 人数
FROM 员工表
GROUP BY 部门
HAVING AVG(薪资) > 10000
ORDER BY 平均薪资 DESC;

-- 窗口函数
SELECT 姓名, 部门, 薪资,
       RANK() OVER (PARTITION BY 部门 ORDER BY 薪资 DESC) as 部门排名
FROM 员工表;

-- 时间序列分析
SELECT DATE_TRUNC('month', 订单日期) as 月份,
       SUM(金额) as 月销售额
FROM 订单表
WHERE 订单日期 >= '2024-01-01'
GROUP BY 月份
ORDER BY 月份;
```

## 六、数据分析思维框架

1. **明确问题** → 业务理解、目标定义
2. **数据收集** → 获取数据、评估质量
3. **数据清洗** → 处理缺失值、异常值
4. **探索分析** → 描述统计、可视化
5. **建模分析** → 选择方法、构建模型
6. **结果解读** → 得出结论、提出建议
7. **报告呈现** → 可视化展示、故事叙述
