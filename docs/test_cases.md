# Aether Engine 系统测试用例 (Strict & Comprehensive)

## 1. 智能体管理 (Agents)
| 用例 ID | 功能点 | 测试场景 | 预期结果 | 严重程度 |
| :--- | :--- | :--- | :--- | :--- |
| AGT-001 | 创建 Agent | 提交合法配置（包含 name, prompt, skills） | 返回 200，且数据库中存在该 Agent 记录 | P0 |
| AGT-002 | 创建 Agent | 缺失必填字段（如 name） | 返回 40001 错误，提示 name 不能为空 | P1 |
| AGT-003 | 列表查询 | 分页查询所有 Agents | 返回符合分页参数的数据量，且包含正确的 `total` | P0 |
| AGT-004 | 更新 Agent | 修改已存在 Agent 的提示词或模型 | 返回更新后的对象，且 `updated_at` 发生变化 | P1 |
| AGT-005 | 删除 Agent | 删除指定 ID 的 Agent | 返回成功，且后续查询该 ID 返回 40400 | P0 |
