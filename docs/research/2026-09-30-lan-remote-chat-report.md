## 使用所需配置

更新前端后重新打开 Aether IDE，在设置中选择远端服务，填写远端地址及该服务器的实例令牌；点击“保存并重启”使连接配置生效。远端工作目录填写**引擎所在机器的绝对项目路径**；留空可使用服务端为会话分配的沙箱。已有会话继承服务端记录目录；想采用新目录时新建会话。

远端已保存的模型会自动加载。没有模型时可从聊天提示进入模型管理，填写服务商、模型 ID、服务商地址和自己的 API Key，再测试连接。产品提供服务商默认地址、模型预设、能力检测和首个可用模型选择。服务器令牌、真实模型密钥与额度不能凭空生成；新的随机客户端 token 也不能自动成为服务器接受的 token。

尚未完整开放的能力及自动审批阻挡，见[限制总览](./2026-09-30-restrictions-index-and-remote-fix.md)。私网/Ollama 模型配置仍有既有 UI 校验限制；远端目录目前验证绝对路径格式，存在性和权限由服务端实际执行报告。
