# 快速上手指南

欢迎使用 AI Agent Engine！本指南将带你从零开始，快速了解如何配置并使用你的 AI 助手。

## 1. 核心概念：你必须要知道的

在开始之前，请先理解这三个核心词：
- **Agent (智能体)**：这是你的 AI 助手的“大脑”。你可以为它设定不同的性格、知识库和可用的工具。
- **Session (会话)**：这是你与 AI 的一次完整谈话。每个会话都有自己独立的**工作区 (Workspace)**。
- **Workspace (工作区)**：这是 AI 的“办公桌”。AI 在这里创建文件、写代码、运行程序。你在界面右侧看到的文件夹就是它。

## 2. 第一步：配置模型

如果你是第一次使用，需要告诉系统使用哪个 AI 模型（如 DeepSeek, Claude, GPT-4）：
1. 点击侧边栏的 **设置 (Settings)**。
2. 输入你的 **API Key**。
3. 选择一个 **主模型 (Primary Model)**。
4. 点击保存。

## 3. 第二步：创建你的第一个 Agent

1. 进入 **Agent 管理** 页面。
2. 点击 **新建 Agent**。
3. 给它起个名字（例如：“全栈开发专家”）。
4. 在 **系统提示词 (System Prompt)** 中告诉它你是谁，希望它怎么帮你。
5. 勾选它需要的 **工具**（推荐全选，让它更强大）。

## 4. 第三步：开始对话

1. 在聊天框输入你的第一个任务。例如：
   > “帮我用 React 写一个简单的待办事项网页，并把它保存在 `todo-app` 文件夹里。”
2. **观察 AI 的思考**：你会看到聊天框上方出现“AI 正在思考...”以及它正在使用的工具卡片。
3. **查看产出**：
   - 观察右侧的 **Explorer (文件浏览器)**，你会发现 `todo-app` 文件夹和代码文件已经自动生成了。
   - 点击文件，你可以在内置的 **编辑器** 中直接查看或修改代码。

## 5. 进阶玩法

### 使用终端 (Terminal)
你可以像在 VS Code 里一样，在下方的终端里运行命令。
- 输入 `npm start` 运行你的项目。
- 输入 `ls` 查看文件列表。

### 自动化任务 (Cron & Todo)
- **待办任务**：你可以对 AI 说“帮我记一下下午3点要开会”，它会自动在顶部的 **Todo 面板** 创建一条记录。
- **定时任务**：你可以说“每天早上9点提醒我总结昨天的代码进展”，AI 会准时为你发起会话。

### 移动端体验
AI Agent Engine 提供移动端适配（`/m` 路由），你可以在手机上：
- 实时对话并查看 AI 思考过程。
- 管理 Todo 任务（支持左滑删除）。
- 查看详细的 Token 消耗统计。
- 快捷切换会话。

### 扩展能力 (MCP & Skills)
- 如果你需要 AI 访问你的 GitHub 或 Google Drive，可以在 **MCP 管理** 中添加相应的服务器。
- 如果你有特殊的业务逻辑，可以编写一个 **Skill (技能)** 脚本，让 AI 调用。

## 6. 常见问题

- **Q: AI 报错“权限不足”怎么办？**
  - A: 检查你的安全策略设置，某些危险命令（如 `rm -rf /`）是被默认禁止的。
- **Q: 如何更换 AI 模型？**
  - A: 在设置中修改 API Key 或主模型，系统会立即生效。
- **Q: 我的文件去哪了？**
  - A: 每个会话都有独立的工作区，点击侧边栏的“历史记录”可以切换回之前的会话并找回文件。
