# HTTP 路由源码目录

本表覆盖当前 `src/api/http/routes/` 的路由声明，包括主路由调用的协作、浏览器、工作区与 Flow 子模块。由 `node scripts/diagnostics/documentation-audit.mjs --write-catalogue` 生成；不启动引擎、不读取用户数据。根路由与 `/api/v1` 前缀按 [server.ts](../../src/api/http/server.ts) 的挂载关系区分。

权限、流生命周期和请求字段说明见 [API 使用约定](api-spec.md)；机器可读版本为 [OpenAPI 路由目录](openapi.json)。未静态展开的 Zod/业务校验必须读相应处理器，不能把空 schema 理解为接受任意请求。插件开发者使用[公开 HTML 参考](../../../aether-code/docs/plugin-api/dist/index.html)。
