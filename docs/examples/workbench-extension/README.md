# 工作台扩展示例

这是 Aether 的可导入工程，声明了当前 12 类贡献、8 个菜单位置和 3 个内嵌位置，用于检查同一个默认界面的挂载、目标上下文和权限。公开协议以 [HTML 插件参考](../../../../aether-code/docs/plugin-api/content/overview.html) 为准，本 README 只说明此示例的实际行为。所有权限默认关闭，先按需要授权。

在「插件 → 开发模式」打开本目录，选择当前会话，按需开启权限，预览页面和测试工具；修改源码后点刷新。正式导航、菜单、hooks 和后台任务需导入、发布、启用后验证，开发预览不会自动注册全部挂载。

会话分析调用平台已配置模型，使用非流式 `ai.run`，会产生正常模型用量。没有指定模型时选择可用列表首项；只读取会话前 50 条，返回 `partial` 表示仍有后续消息，不能把部分分析当作完整会话结论。生产插件应继续按 `nextOffset` 分页。此示例没有启动插件 Agent，也未申请 `agents.manage` 或 `engine.tools`。

`inspect_context` 在宿主内读取真实 `$AE.context()`，业务参数 `_context` 仅供不带宿主的独立测试夹具使用，不能覆盖运行时身份。可从消息、文件、输入框等入口检查传入目标；代码预览的编辑器目标当前只读，Office、PDF 和图片预览不是此接口目标。

原生页面只演示 JSON 组件与输入字段绑定，工具结果显示为回执，没有异步数据源或自动绑定结果到组件属性。Webview 页面提供上下文查看、会话分析、复制和通知，不演示全部 SDK。浏览器插件标签复用沙箱页面，不提供普通网页控制权。

示例服务未声明会话作用域，因此是全局服务；启动只调用 `inspect_context`，返回后即完成，没有计时器或长期执行。需要查看会话工作区的活跃服务时，应另用声明会话作用域且返回运行状态的示例，不能用这里的全局服务判断会话列表是否遗漏。

后台 `heartbeat` 每分钟更新本插件设置，启动时也执行一次；需要 `background.run`、`settings.read`、`settings.write`，且仅在发布、启用并授权后调度。它不写工作区、不调用模型。停用会停止调度。桌面内置引擎随应用退出停止，下次引擎启动恢复；远端引擎的运行不由本地窗口退出决定。

「工具测试」的两条样例只验证确定性输出。会话分析、系统交互、各实际挂载与后台恢复需分别验证；样例通过不代表这些宿主行为已验证。平台注入 `$AE`，不用配置第二套模型密钥。
