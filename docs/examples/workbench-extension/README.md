# 工作台扩展示例

这是 Aether 的可导入工程，包含真实会话分析、宿主组件页面、菜单和内嵌界面，以及可选的持久后台计数任务。所有权限默认关闭；先按要验证的功能授权。分析调用平台已配置模型，会产生正常模型用量。

在「插件 → 开发模式」打开本目录，选择当前会话，按需开启权限，打开页面进行验证。修改源码后点刷新即可，不需要安装卸载。会话分析当前只取前 50 条；返回 `partial` 表明是否还有后续内容，生产插件应按 `nextOffset` 分页。

后台 `heartbeat` 每分钟更新此插件自己的设置，需要 `background.run`、`settings.read`、`settings.write`，且只有发布、启用并授权后才调度。它不写工作区，不调用模型。停用插件可停止任务；从托盘退出会停止整个 Aether，下次启动恢复持久调度。

可在插件管理中导入本目录或包含根清单的 ZIP，再测试、发布和启用。开发期间直接打开源码目录并刷新即可。

「工具测试」中的两条样例只验证确定性输出。会话分析需绑定会话并授权模型与消息读取；后台任务需发布、启用并授权后验证。平台会注入 `$AE`，不需要配置第二套模型密钥。
